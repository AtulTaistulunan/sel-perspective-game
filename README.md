# 換個位置看看

國小五年級「綜合活動 × SEL（社會情緒學習）」的 2D 像素 RPG 小遊戲，約 8 分鐘。

學生先用主角的眼睛經歷「分組被拒絕」，再換成組長的眼睛看同一件事，最後練習用「停、想、說、找」化解衝突。

## 怎麼玩

用平板或電腦的瀏覽器開啟網站即可，不需安裝、不需帳號，也不會蒐集任何學生資料。

1. 輸入自己的名字、替組長取一個稱號，並選擇兩人的性別
2. 點地板帶角色走路，走到人物旁邊就會開始對話
3. 依照劇情做選擇；選了傷人的回應，會先看到對方的反應，再進行換位思考

## 課綱對應

- 核心素養：綜-E-C2
- 學習表現：2a-III-1、2b-III-1
- 學習內容：Ba-III-2、Ba-III-3、Bb-III-2

## 製作

- 教學設計、劇本、程式：教師與 Claude（Anthropic）協作
- 角色、場景、圖示：教師以 ChatGPT（GPT Image）生成
- 字體：jf open 粉圓（Huninn，SIL Open Font License），由 Google Fonts 載入
- 背景音樂：原創旋律，由瀏覽器即時合成

## 修改台詞

用文字編輯器打開 `index.html`，檔案開頭的「老師可以修改的區域」包含所有台詞、選項與回饋。只改引號裡的文字即可。
